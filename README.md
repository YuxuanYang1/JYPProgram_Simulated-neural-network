*V0.0* <br/>
这个模型可以进行XOR逻辑学习 <br/>
用以下代码替换X&Y <br/>
AND 门 <br/>
X = [[0,0],[0,1],[1,0],[1,1]] <br/>
Y = [[0],[0],[0],[1]] <br/>
OR 门 <br/>
